# 01-ts-basics

Домашнє завдання №1: основи TypeScript (типізація даних, функцій та асинхронних операцій).

Кожне завдання знаходиться в окремому файлі `src/task-1.ts` … `src/task-8.ts`.

```bash
npm install
npm run dev        # запуск, результати в консолі браузера
npm run typecheck  # перевірка TypeScript
npm run format     # Prettier
```
